# Contributing to SMPE
### Critical Issues
Things that not everyone should know about (e.g. item duplication, incorrect permissions) can be reported [here](https://github.com/KEL0002/SMPE/security/advisories/new)
### Bugs, Questions, Suggestions, etc.:
You are always welcome to do these things in the [issues page](https://github.com/KEL0002/SMPE/issues)
### Contributing your own Code via Pull requests
Please **do not create pull requests without getting my permission**. If you want to implement a feature, first create an issue with what you would like to do and mention that you would like to code this yourself.
When you have my permission, do not copy any code directly from AI, and make sure your code should work with all versions this plugin is currently available for.
